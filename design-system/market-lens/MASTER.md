# Market Lens 交易研究台

更新：2026-10-23。实现：React 19、TypeScript、Tailwind CSS 4.3、Vite、Bun。

## 设计选择

界面采用交易终端的三栏工作台：自选与持仓、主图与计划、指标证据。中等屏幕优先给图表完整宽度，指标证据移到图表后。移动端保留搜索与来源切换，日期、周期、图表工具可换行。

UI/UX Pro Max 搜索采用 Flat Design 的克制层次、清晰边界和快速反馈建议。检索返回的 Feature-Rich Showcase 首页结构与本产品不符，不采用；本文件记录实际实现选择，而非将推荐首页误当交易终端。

## 样式架构

- `tokens.css`：所有语义色、字体、尺寸与动态效果令牌。
- `src/workspace-theme.css`：Tailwind theme 映射、组件规则与响应式。保留旧业务模块样式兼容，逐步按组件迁移。
- Tailwind 通过官方 `@tailwindcss/vite` 插件编译；仅引入 theme/utilities，避免 Preflight 意外重置现有表单、表格与 Canvas 宿主。
- `src/WorkspaceChrome.tsx`：顶栏、导航、标题及证券报价组件。不得使用静态HTML替代React状态及回调。

## 色彩与字体

背景 #0c0e14，表面 #151923，次表面 #12151e，抬升表面 #202534，边界 #2a3040，强调 #b5a3ff。紫色表示操作和选中，不冒充价格涨跌。价格涨跌沿用独立语义令牌及箭头。

保留 Space Grotesk 数据/标题与 IBM Plex Sans 正文，中文回退 Microsoft YaHei。表格使用等宽数字。主要说明和指标采用12px阅读底线，图表刻度及密集元数据根据空间使用10–11px；页面标题25–27px、报价25–32px。

图表保持原四条MA固定身份、线型区别和文字图例。系列 #3987e5 / #d95926 / #199e70 / #a265d4 在新表面通过 dataviz 亮度、彩度、色觉模拟、普通视觉差异与对比度校验。价格、成交量和震荡指标保持独立窗格。

## 交互与边界

- 所有导航有真实锚点或设置回调；键盘可跳转到图表。
- 自选面板与主图等高，仅证券区域滚动；代码换行，持仓数量独立列。
- 报价旁明确比较口径。开、高、低、成交量为最近K线数据，不假称实时日内汇总。
- 不生成胜率承诺、市场指数、虚构账户资产或未经计算的评分。
- 表格、策略规则、计划、扫码、导出和实时状态保留业务能力。
- reduced-motion关闭非必要过渡；focus-visible继续提供明确轮廓。
- 验证宽度320 / 375 / 414 / 768 / 1024 / 1536px及移动横屏，无页面横向溢出。
