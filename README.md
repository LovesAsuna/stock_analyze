# 观势 Market Lens

个人港美股技术分析与交易复盘工作台。使用 **Longbridge CLI** 作为真实数据源，**TradingView Lightweight Charts 5** 绘制价格、成交量与指标，React 19 + TypeScript + Tailwind CSS 4 + Vite 构建界面，本地 Bun 服务隔离账户凭证。

## 启动

要求 **Bun 1.4.3 或更新版本**，已安装 Longbridge CLI。依赖安装、开发服务、TypeScript 检查、Vite 构建、生产服务与测试均由 Bun 驱动；不需要全局安装 tsx、concurrently 或 Node.js。浏览器验收使用本机 Google Chrome。

```bash
bun install --frozen-lockfile
bun run dev
```

打开 http://127.0.0.1:5173 。默认是明确标记的合成演示数据；右上角切换为“Longbridge 本机”即可读取当前 CLI 已登录账户。

`bun.lock` 是唯一依赖锁文件。开发模式由 Bun 并行启动 API 的 TypeScript watch 与 Vite，停止开发命令会一并停止子任务。`bun test` 只发现领域单元测试；浏览器测试通过独立的 `bun run test:e2e` 入口执行。

CLI 未登录时，在本机终端运行：

```bash
longbridge auth login
longbridge check
```

右上角“数据源”旁的“登录长桥”可打开网页行情登录弹窗。点击“生成登录二维码”，使用长桥 App 扫码并在手机确认；成功后入口显示“长桥已登录”，可打开弹窗退出本次登录。关闭尚未完成的扫码会先取消请求，过期可重新生成。

网页扫码只登录独立的原生行情会话；持仓、成交流水、历史及 CLI 备用报价仍使用 CLI 登录账户，请确认两处账户一致。网页会话凭据只保存在隔离子进程，不写入浏览器存储；已登录进程保留至显式退出、服务停止或故障清理，服务重启后重新扫码，不读取桌面应用已有登录。真实行情权限仍取决于登录账户。

CLI 凭证由 CLI 保管，不需要在网页输入密钥。当前实现不会下单。仅绑定 `127.0.0.1`，接口检查 Host / Origin，不提供 CORS；这属于本机个人工具，部署到公网前需要增加认证和账户隔离。

生产模式：

```bash
bun run build
bun run start
```

打开 http://127.0.0.1:8787 。开发模式与生产模式的服务均占用 8787 端口，请先停止另一实例。

## 信号与复盘口径

页面当前使用交易计划驱动规则。默认“趋势研究计划”为快均线 > 慢均线且 MACD 柱 > 0 时观察入场，收盘价 < 慢均线时离场；默认止损3%、止盈6%、最长20柱，数量100股，初始资金100000（标的计价币种），费用10bps、滑点5bps均为单边。所有条件及参数可编辑，这些是体验模板，不是经样本外验证的交易建议。

点击“建立交易计划”或“编辑计划”，选择全部/任一条件、指标比较或交叉，再配置风险、数量与有效期。图上取价只进入草稿，保存后才生效；观察入场价是收盘下限过滤，不是限价挂单。固定止损/目标优先于对应百分比。计划按来源、证券、周期隔离，保存修订保留历史；优先保留每个上下文的最新计划，历史容量100条、每计划最多10版，达到100个活跃上下文明确拒绝新增。

回测采用单证券、只做多、固定数量现金账户；已持仓不再次加仓，费用与不利滑点实际进入现金账本，资金不足则拒绝模拟入场。规则和风险统一收盘确认，下一已确认柱开盘模拟执行。这个保守的数据模型需要下一柱收盘后才将其开盘计入结果；不是实时券商订单。未确认柱不用于成交、估值和完整绩效。止盈触发之后仍可能因次柱跳空而亏损。有效期末不强制平仓。

回测结果显示已加载历史预热后的实际研究范围；下方真实成交核对使用单独选定的中国时间范围。历史重算不证明当时已经建立计划。入场路径图以每笔原始开盘为基准，offset0=0，offset1=入场柱收盘；只聚合仍持仓的样本，长周期样本数会减少，分位区间不是未来预测。

信号只用当前及过去已确认数据；至少 200 根确认 K 线之后才发出。下一柱及后五柱只用来做事后对照，不参与信号生成。SAR 是路径依赖指标，历史起点、初始化、复权方式不同可能与券商软件不同，应以用户软件读数校准。

执行核对限定为信号确认后的**下一根 K 线窗口**内首笔同向成交，每笔成交最多匹配一次。如果成交查询闭开区间未覆盖完整匹配窗口，未匹配项显示未知。扩展执行核查还可寻找第2–5柱的延后成交候选，直接窗口匹配优先。延迟包含休市等待，价格偏差是实际价减下一柱开盘，不是归因或净盈亏。

仓位流水需要用户明确输入成交区间起点的数量（空仓填0）和可选单位成本；数据只在当前面板内存使用，切换来源、标的、周期或区间后清除。无期初、成交不完整、卖超或同秒异向先后不明时保守显示未知。分类建仓/加仓/减仓/清仓，并按数量寻找先卖后买候选；移动平均成本价差和候选价差不含费用、税、汇率或公司行动。任何未执行信号都不会自动换算成“少赚金额”。

本页监控须保存计划后手动开启，每75秒刷新一次，只记录启用之后新确认的信号，保存当时规则版本、触发柱和指标快照。使用回测模拟仓位决定入场/离场，不读取真实持仓来决定信号。修改版本、改变复盘范围或历史数据起点会停用监控；切换回来或重新加载页面不会自动恢复。浏览器关闭/休眠时不保证检查，不是后台服务，也不发送券商订单。

“后 5 根价格变化” = `(第5根收盘 / 下一根开盘 − 1) × 100%`。第五根未结束显示 `—`，不计算手续费、滑点和资金限制，不代表可实现盈亏。暂不包含期权时间价值或 Greeks。

中国时间范围是周一 00:00 至周六 00:00 的闭开区间。美股按美东时区处理 DST；美股周五收盘通常已是中国周六，因此被排除。标准港美股日线采用当地 16:00 收盘，未接入半日市日历；半日市会延迟确认。日内柱在港股午休和标准收盘边界截断确认，收盘同步另保留 60 秒缓冲。

## 数据实现与限制

真实数据调用：

- `longbridge watchlist --format json`
- `longbridge positions --format json`
- `longbridge kline history SYMBOL --period ... --start ... --end ... --adjust none --session intraday --format json`
- `longbridge order executions --history --symbol ... --start <RFC3339 +08:00> --end ... --format json`

历史按周期分块：1 分钟每块 2 个自然日、5 分钟每块 7 日、15 分钟每块 28 日，其余周期使用相应窗口；并发最多 2、总计最多 48 次，合并去重后再计算指标。分块触及 CLI 单次 1000 根上限会明确报错。1 分钟复盘起点至当前最多 30 个自然日，5 分钟最多 90 日；旧区间过大时需缩短范围或使用更长周期。页面自定义复盘范围仍为 1–93 天。

季 K 使用完整月 K 聚合，取首月开盘、最高、最低、末月收盘及成交量总和；缺首月、中间月或已结束季度末月的数据不会伪装成完整季度。实时季度更新也读取月线后聚合。周、月、季、年按交易所日历周期的末个工作日标准收盘确认；未接入完整节假日及半日市日历，可能延迟确认。较长周期或上市历史短的证券可能不足 200 根，因此不生成策略信号。

分时使用 `longbridge intraday SYMBOL --session all` 读取当日，历史日期追加 `--date YYYYMMDD`。分时按钮旁可选夜盘/盘前/盘中/盘后/全部；“5 日”沿用当前时段，向前最多 12 个交易所自然日查找最近 5 个有数据的交易日，不足时显示实际数量及提示。港股不提供的扩展时段直接显示空状态。价格、均价、成交量独立于 K 线，保留真实 UTC 时间，横轴按交易所时区显示；午休、跨日和缺失分钟断开连线。

真实分时每 15 秒串行刷新快照，与顶部实时报价独立。分时权限、历史可用天数和字段取决于 CLI 与账户；没有数据或读取失败会显示提示，不以其他时段或合成数据填充。本机验收已取得真实夜盘及盘前点，但指定历史日期为空，尚未验证取得完整五个真实交易日。

只通过 `execFile` 固定参数数组执行，不拼接 shell 命令。每条命令超时 45 秒，响应在内存缓存 60 秒，合并重复并发请求。错误日志不输出账户记录或凭证。

当前选择**不复权**，保证成交价格与图表使用同一价格口径；遇到拆股可能出现指标失真，需要人工核查。报价通过上游WebSocket推送，浏览器的 `GET /api/stream?source=longbridge&symbol=...&period=...` 为同源只读SSE。界面分别显示行情时间、连接状态与交易时段，断线时保留旧值并明确提示重连。

桌面通道源自会话 `2d3c6623-8348-472f-8615-f3675a21182f` 的已验证实现：独立子进程加载已安装Longbridge Pro原生引擎，隔离APPDATA/LOCALAPPDATA/USERPROFILE，不读取桌面登录凭据；认证后订阅，重连后恢复，多证券通过搜索解析内部标识。默认安装路径为 `C:/Program Files (x86)/Longbridge Pro`，可用 `LONGBRIDGE_INSTALL_DIR` 指定。隔离 worker 明确使用与主服务相同的 Bun 可执行文件；本机 Bun 1.4.3 已验证原生 addon 初始化、双向 IPC 和退出后临时目录清理。该能力仍依赖本机 Windows x64 桌面引擎版本。兼容约定变化会显示错误并回退CLI，不猜测协议或借用桌面会话。

原生通道启动时，从当前安装配套 `app.asar` 的主进程静态配置自动识别 global 生产端点，不执行包内代码，也不读取桌面用户设置或登录数据。复用同版桌面的 `geoTest` 地域判断，并在最多 5 秒内并行检查候选 HTTP/双 WS 端点的 TLS 连通性；首选区域不可用时使用另一组可用端点，HTTP 与双 WS 始终来自同一区域。服务日志显示选中的 `bj`（大陆）或 `hk`（香港）；配置缺失、歧义或升级后格式不兼容显示 `[ENDPOINT_CONFIG]`，所有区域均无法连接显示 `[ENDPOINT_UNAVAILABLE]`，不回退到硬编码地址。区域在隔离进程启动时选定，重启进程时重新识别和探测。

CLI备用通道需要支持 `serve` 的版本（本机验证0.30.0），只允许行情读取、订阅与取消订阅RPC；复用CLI自身已登录状态。行情快照与增量按时间合并，旧推送不覆盖新价格。原生K线通过CLI长连接的 `quote.candlesticks` 每5秒同步，不从tick价格、日内累计成交量自行拼OHLCV；首次及断线恢复补最多1000柱，保留既有长历史起点。K线维持常规时段和60秒收盘同步缓冲，顶部盘前/盘后价格与图表时段分别标注，未确认柱不产生已确认信号。

同一证券、周期的客户端共享读取；未登录时，服务只在有订阅时运行行情进程和定时器。切换来源/证券/周期或关闭页面会释放订阅；已扫码登录的原生会话保留至显式退出、服务停止或故障清理。SSE有心跳、连接上限与缓冲上限。页面监控仍需手动开启；75秒HTTP刷新作为历史与成交补查，同时接收实时K线确认更新。权限与延迟取决于上游服务、账户权限及网络状态。

AP 账户历史逐笔成交接口已适配。美国地区账户若不支持该端点，显示执行状态未知；不会拿聚合订单的平均价和更新时间冒充逐笔成交。自动获取历史期初、外部转入转出、多账户跨币种汇总、期权专业复盘、后台常驻监控、跨证券扫描、自动趋势线/形态/斐波那契绘图、多证券整周汇总仍属于后续开发范围。

演示数据是确定性合成 OHLCV、模拟持仓和部分模拟成交，截止 2026-10-16，不对应真实行情或用户账户。旧 Node/V8 数据基准保存在 `tests/fixtures/legacy-demo/` 并继续校验原 SHA-256；Bun/JSC 与 V8 的双精度末位差异采用实测严格容差逐根核对，时间、成交量、确认状态、信号及演示成交的离散字段仍精确比较。生产生成算法没有为通过测试而改写。

事件数据使用 Longbridge `news search`、`news SYMBOL`、`filing SYMBOL`、`finance-calendar macrodata` 和 `finance-calendar report`，仅在打开相应入口时请求。新闻/公告过滤为当前时刻往前7天，日历为近7天至未来30天；服务端再次校验日期、去重及限量，每来源最多30条、合计最多120条，缓存60秒。全局新闻为“美联储 利率 通胀”和“战争 地缘”主题检索样本，不保证覆盖全部议息会议、战争动态或重大新闻。部分来源失败保留可用数据并提示，全失败报错，不混入演示事件。没有当地有效日期的财报不把日历占位时间冒充披露时刻；链接只接受无内嵌凭证的HTTP/HTTPS地址。

## 目录

- `src/`：交互工作台与 TradingView 图表。
- `shared/`：领域模型、指标、信号和时间/执行复盘引擎。
- `server/`：只读 Longbridge 适配、演示源与 HTTP 边界。
- `tests/`：指标、时间语义、数据边界和浏览器交互检查。
- `tokens.css`：界面及图表统一视觉令牌。

### 原生行情模块职责

- `engine-client.cjs`：父进程匿名环境、子进程启动/退出屏障及受限 IPC 生命周期。
- `bootstrap.cjs`：子进程隔离校验、同版引擎与资源加载、一次 ASAR 读取、自动端点选择及初始化诊断。
- `worker.cjs`：报价目标订阅、重连、事件确认与 IPC 派发；扫码通过独立会话协调报价身份切换。
- `auth-session.cjs`：扫码请求、有效期、取消代及隔离 HTTP 凭据写入，不管理报价目标或父进程引用。
- `market-access.cjs` / `helpers.cjs`：通用只读行情 HTTP、精确证券搜索、期权链身份及会话代数校验。
- `quote.cjs` / `candles.cjs` / `intraday.cjs`：各自领域数据校验、快照合并或读取编排；保留不同的数字文法与回退边界，不互相依赖领域模块。
